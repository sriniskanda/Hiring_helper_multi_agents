This is open-source project about hiring helper multi-agent using LangChain and LangGraph. 
Hiring_helper.py takes list of resumes in (.pdf) files inside Resume folder and matches with the JD present inside JD folder.
This multi-Agent framework parses the list of resumes, analyze, Reason and finally generate the Report in excel sheet.
Output is Excel sheet with various fields such has candidates Education, Skills, Work Experience, Skills etc. Also provide depth analysis	such as analysis_summary, additional_achievements, ratings_sentiment.
This makes HR to filter, analyze, report candidates quickly and effectively.
